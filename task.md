# Разработка шлюза ModbusTCP - ModbusRTU

## Задачи
- слушать запросы на COM порту по modbusRTU 
- переадресовывать их на устройство по modbusTCP 
- ответ возвращать обратно по RTU
- tcp устройство может быть удаленным
- Среда разработки Delphi 13 и выше
- Программа небольшая утилита с UI. задание параметров и номера COM, задание адреса IP, кнопка старт стоп, состояние, логирование по запросу.
